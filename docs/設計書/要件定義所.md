# 要件定義書

## 1. 概要

### 1.1 ShipIt!

ポートフォリオ共有・探索サービス

### 1.2 目的

- 主に初学者や転職活動中のエンジニアが、他者のWebアプリポートフォリオを条件付きで検索及び共有できるようにする。
- 実装内容・技術スタック・スコープを構造化し、「何をどこまでやったか」が一目でわかる状態を目指す。
- 投稿者にとっては、自身のポートフォリオの棚卸・説明コスト削減を目的とする。

### 1.3 対象ユーザー

- 未経験エンジニア
- 実務経験1年未満エンジニア
- 実務経験1～3年未満エンジニア

※主対象ではないが3年以上のエンジニアも利用することが出来る。

## 2. 技術スタック

### 2.1 フロントエンド

- Next.js 15
- Tailwind CSS
- テスト：Vitest

### 2.2 バックエンド

- Ruby 3.3.0
- Rails 8.0（APIモード）
- テスト：RSpec

### 2.3 データベース

- PostgreSQL

### 2.4 デプロイ

- フロントエンド：Vercel
- バックエンド：AWS ECSなど

### 2.5 CI/CD

- GitHub Actions

### 2.6 環境構築

- Docker

## 3. 機能要件

## 3.1 MVP対象機能

- 認証機能
  - ユーザー登録
  - ログイン / ログアウト（Devise）
  - マイページ表示
- ポートフォリオ投稿機能（CRUD）
  - 新規登録
  - 編集
  - 削除（物理削除）
  - 詳細表示
- 検索機能
  - AND条件によるフィルタリング
  - 技術スタック
  - 経験年数帯（未経験、実務経験1年未満など）
  - 並び替え（新着順など）
- フォロー機能
  - ユーザーのフォロー / アンフォロー
  - フォロー中ユーザーの投稿一覧
- リアクション機能
  - 参考になった（いいね）機能
  - 1ユーザー1投稿につき1いいね
- 入力進捗バー
  - 投稿入力中に進捗率（％）を表示
  - 入力項目数に応じて自動計算

### 3.2 今後拡張予定機能

- コメント機能
- タグ自由入力

## 4. 非機能要件

### 4.1 パフォーマンス

- 一覧表示はページネーション前提（20～30件を想定）

### 4.2 セキュリティ

- 認証必須操作（投稿・フォロー・いいね）
- CSRF / XSSの基本対策

### 4.3 保守性

- APIとフロントエンドの分離
- テストコードによる正常性の確約

## 5. 画面一覧（簡易）

| マイページ         | 自分の投稿・ユーザー情報編集など |

## 6. その他

- 実装過程において、要件の調整が発生する可能性あり。
